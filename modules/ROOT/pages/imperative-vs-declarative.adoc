==== Imperative vs Functional/Declarative Programming Cheat Sheet

*Imperative programming* focuses on *how* to achieve a result through
explicit step-by-step instructions, often involving mutable state and
loops.

*Functional (declarative) programming* focuses on *what* the result
should be, using pure functions, immutability, recursion, and
higher-order functions.

Here we compare common problems using: - *Ruby* for imperative style
(mutable variables, loops). - *Elixir* for functional style
(immutability, recursion, `Enum` module, comprehensions).

===== 1. Summing a list of numbers

*Ruby (Imperative)*

[source,ruby]
----
numbers = [1, 2, 3, 4, 5]
sum = 0
numbers.each do |n|
  sum += n  # Mutation
end
puts sum  # => 15
----

*Elixir (Functional)*

[source,elixir]
----
numbers = [1, 2, 3, 4, 5]
sum = Enum.sum(numbers)
IO.puts(sum)  # => 15
# Or with reduce:
Enum.reduce(numbers, 0, fn n, acc -> acc + n end)
----

===== 2. Mapping (transforming) each element (e.g., double)

*Ruby (Imperative)*

[source,ruby]
----
numbers = [1, 2, 3]
doubled = []
numbers.each do |n|
  doubled << n * 2  # Mutation
end
p doubled  # => [2, 4, 6]
----

*Elixir (Functional)*

[source,elixir]
----
numbers = [1, 2, 3]
doubled = Enum.map(numbers, &(&1 * 2))
IO.inspect(doubled)  # => [2, 4, 6]
# Or comprehension:
for n <- numbers, do: n * 2
----

===== 3. Filtering even numbers

*Ruby (Imperative)*

[source,ruby]
----
numbers = [1, 2, 3, 4, 5]
evens = []
numbers.each do |n|
  evens << n if n.even?
end
p evens  # => [2, 4]
----

*Elixir (Functional)*

[source,elixir]
----
numbers = [1, 2, 3, 4, 5]
evens = Enum.filter(numbers, &(rem(&1, 2) == 0))
IO.inspect(evens)  # => [2, 4]
# Or comprehension:
for n <- numbers, rem(n, 2) == 0, do: n
----

===== 4. Looping n times (e.g., print "`Hello`" 5 times)

*Ruby (Imperative)*

[source,ruby]
----
5.times do |i|
  puts "Hello #{i + 1}"
end
----

*Elixir (Functional – Recursion)*

[source,elixir]
----
def print_n_times(_msg, 0), do: :ok
def print_n_times(msg, n) do
  IO.puts(msg)
  print_n_times(msg, n - 1)  # Tail-recursive
end

print_n_times("Hello", 5)
# Or with Enum:
Enum.each(1..5, fn i -> IO.puts("Hello #{i}") end)
----

===== 5. Factorial of a number

*Ruby (Imperative)*

[source,ruby]
----
def factorial(n)
  result = 1
  i = 1
  while i <= n
    result *= i
    i += 1
  end
  result
end

puts factorial(5)  # => 120
----

*Elixir (Functional – Tail Recursion)*

[source,elixir]
----
def factorial(n, acc \\ 1)
def factorial(0, acc), do: acc
def factorial(n, acc), do: factorial(n - 1, acc * n)

IO.puts(factorial(5))  # => 120
----

===== 6. Finding the maximum in a list

*Ruby (Imperative)*

[source,ruby]
----
numbers = [3, 1, 4, 1, 5]
max = numbers[0]
numbers.each do |n|
  max = n if n > max
end
p max  # => 5
----

*Elixir (Functional)*

[source,elixir]
----
numbers = [3, 1, 4, 1, 5]
max = Enum.max(numbers)
IO.inspect(max)  # => 5
# Or reduce:
Enum.reduce(numbers, &Kernel.max(&1, &2))
----

===== 7. Reversing a list

*Ruby (Imperative)*

[source,ruby]
----
list = [1, 2, 3]
reversed = []
list.each do |item|
  reversed.unshift(item)  # Mutation
end
p reversed  # => [3, 2, 1]
----

*Elixir (Functional)*

[source,elixir]
----
list = [1, 2, 3]
reversed = Enum.reverse(list)
IO.inspect(reversed)  # => [3, 2, 1]
# Or recursive:
def reverse([]), do: []
def reverse([head | tail]), do: reverse(tail) ++ [head]
----

*Key Takeaways* +
- Imperative (Ruby): Explicit control flow, mutation, easier for
beginners but can lead to bugs in complex code. +
- Functional (Elixir): Immutable data, pure functions,
recursion/higher-order functions → more predictable, easier concurrency,
better for large-scale systems.

This cheat sheet highlights how functional style often results in
shorter, more expressive code for common data transformations!
