= Docs

This is documentation for my personal use. This repo is similar to
notes, but programming specific.

== Generate website

`antora antora-playbook.yml`

== Build

`docker build -t joshua-docs .`

== Run locally

`docker run -d -p 80:8080 --name joshua-docs joshua-docs`

== URL

https://docs-cold-feather-6914.fly.dev/joshua-docs/index.html

== Deploy

`fly deploy`

== Create a nav.adoc from adoc files in pages dir

[source,sh]
----
ls pages | parallel "echo \* xref:{}[]" > nav.adoc
----
