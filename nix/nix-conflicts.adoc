== Options

you don't have to do anything - nix already removed home-manager-path.

nix profile remove /nix/store/d9rzshpw6kzy1bp6rfnz96vsz321kqhy-home-manager-path
removing 'home-manager-path'

but here are some options:

- pick one: gnu or the rust version (nix profile remove utils|home-manager-path)
- set priority (they both currently have 5 ... lower is higher priority): nix profile add flake:nixpkgs#legacyPackages.aarch64-darwin.uutils-coreutils --priority 4
- BEST: install regular core utils :)
